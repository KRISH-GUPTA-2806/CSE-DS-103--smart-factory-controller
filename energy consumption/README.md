# 🧠 What Is This Project?

The **Smart Factory PLC-Lite Automation Controller** is a system designed to help automate small and medium-sized factories.

In simple words, think of it as a **smart brain for a factory**.

It can:

- 💡 Control lights
- 🌀 Control fans
- 🌬️ Control exhaust systems
- ⚙️ Monitor machines
- 📊 Track energy usage
- 👥 Count people
- 🌐 Send information to an IoT dashboard
- 🚨 Detect unusual activity
- 🤖 Use data to improve energy usage
- 🔄 Automatically switch equipment ON/OFF

The main idea is to make factory operations **smarter, safer and more energy efficient**.

---

# 🤔 What Does "PLC-Lite" Mean?

A **PLC (Programmable Logic Controller)** is a type of computer commonly used in factories to control machines.

For this project, we are creating a simpler version of a factory controller.

That's why we call it:

> **PLC-Lite**

You don't need to know PLCs before starting this project.

The concepts can be learned step by step.

# 🎯 Main Goals

The project aims to:

### ⚡ Save Energy

Monitor electricity usage and reduce unnecessary power consumption.

### 🏭 Automate Factory Equipment

Automatically control devices such as:

- Lights
- Fans
- Exhausts
- Machines

### 👥 Improve Safety

Use sensors to understand whether people are present in an area.

### 📊 Monitor Operations

Show important factory information on a dashboard.

### 🚨 Detect Problems

Identify unusual equipment behavior so that possible problems can be noticed earlier.

### 🌐 Enable Remote Monitoring

Allow factory information to be viewed through an IoT-based system.
